# 鱼眼六点透视 (球极投影) 公式

## [1] 输入参数 (Inputs)
* 视界圆心坐标：(X_O, Y_O)
* 视界圆半径：r
* 三个灭点的极角：θ_1, θ_2, θ_3 (分别对应 X轴、Y轴、Z轴的正向延伸射线)
  (注：这三个射线构成的任意角在 90° 到 180° 之间)

* 目标网格点：K(x, y) —— 用于计算经过该点的透视网格圆

---

## [2] 预计算常量 (Pre-computations)
由于三组灭线圆的正交刚性约束，我们可以直接通过夹角算出所有常数。

夹角的余弦值（这三个值必定都为负数）：
* c_12 = cos(θ_1 - θ_2)
* c_23 = cos(θ_2 - θ_3)
* c_31 = cos(θ_3 - θ_1)

三个灭线圆心到视界圆心 O 的有向距离 (p, q, s)：
* p = r * sqrt( -c_23 / (c_12 * c_31) )
* q = r * sqrt( -c_31 / (c_23 * c_12) )
* s = r * sqrt( -c_12 / (c_31 * c_23) )

三个灭线圆的真实半径 (r_1, r_2, r_3)：
* r_1 = sqrt( p^2 + r^2 )
* r_2 = sqrt( q^2 + r^2 )
* r_3 = sqrt( s^2 + r^2 )

---

## [3] 三个灭线圆方程 (Vanishing Line Circles)
灭线圆 P, Q, R 的圆心坐标为：
* P_center = (X_O + p * cos(θ_1),  Y_O + p * sin(θ_1))
* Q_center = (X_O + q * cos(θ_2),  Y_O + q * sin(θ_2))
* R_center = (X_O + s * cos(θ_3),  Y_O + s * sin(θ_3))

圆方程：
* 圆 P (X轴灭线): (X - P_center_x)^2 + (Y - P_center_y)^2 = r_1^2
* 圆 Q (Y轴灭线): (X - Q_center_x)^2 + (Y - Q_center_y)^2 = r_2^2
* 圆 R (Z轴灭线): (X - R_center_x)^2 + (Y - R_center_y)^2 = r_3^2

---

## [4] 六个灭点坐标 (Six Vanishing Points)
灭点必定落在原始射线上，成对出现（正极点与反极点）。
定义各灭点距离原点 O 的有向距离：

X轴方向 (落在角 θ_1 的直线上，为圆 Q 和圆 R 的交点):
* d_1+ = (-r^2 + r * r_1) / p
* d_1- = (-r^2 - r * r_1) / p
* 灭点 D1: (X_O + d_1+ * cos(θ_1),  Y_O + d_1+ * sin(θ_1))
* 灭点 D2: (X_O + d_1- * cos(θ_1),  Y_O + d_1- * sin(θ_1))

Y轴方向 (落在角 θ_2 的直线上，为圆 P 和圆 R 的交点):
* d_2+ = (-r^2 + r * r_2) / q
* d_2- = (-r^2 - r * r_2) / q
* 灭点 E1: (X_O + d_2+ * cos(θ_2),  Y_O + d_2+ * sin(θ_2))
* 灭点 E2: (X_O + d_2- * cos(θ_2),  Y_O + d_2- * sin(θ_2))

Z轴方向 (落在角 θ_3 的直线上，为圆 P 和圆 Q 的交点):
* d_3+ = (-r^2 + r * r_3) / s
* d_3- = (-r^2 - r * r_3) / s
* 灭点 F1: (X_O + d_3+ * cos(θ_3),  Y_O + d_3+ * sin(θ_3))
* 灭点 F2: (X_O + d_3- * cos(θ_3),  Y_O + d_3- * sin(θ_3))

---

## [5] 经过输入点 K(x,y) 的三组透视网格圆方程
给定任意平面坐标 K(x, y)，会有三条透视弧线穿过它，分别汇聚于上面算出的三对灭点。

首先计算点 K 相对原点的几何量：
* dx = x - X_O
* dy = y - Y_O
* D_k^2 = dx^2 + dy^2

### 1. 汇聚于 X 轴灭点 (D1, D2) 的透视圆：
点 K 在 θ_1 射线方向及其法线方向的投影：
* u_1 = dx * cos(θ_1) + dy * sin(θ_1)
* v_1 = -dx * sin(θ_1) + dy * cos(θ_1)

如果 v_1 == 0，说明点 K 正好在射线上，此时该网格线退化为直线：
* 退化直线方程: -sin(θ_1) * (X - X_O) + cos(θ_1) * (Y - Y_O) = 0

如果 v_1 != 0，圆心偏移量 λ_1 为：
* λ_1 = (D_k^2 + 2 * (r^2 / p) * u_1 - r^2) / (2 * v_1)

该网格圆的圆心 (C_x1, C_y1) 与半径 R_k1：
* C_x1 = X_O - (r^2 / p) * cos(θ_1) - λ_1 * sin(θ_1)
* C_y1 = Y_O - (r^2 / p) * sin(θ_1) + λ_1 * cos(θ_1)
* R_k1 = sqrt( (r * r_1 / p)^2 + λ_1^2 )
* 网格圆方程: (X - C_x1)^2 + (Y - C_y1)^2 = R_k1^2

### 2. 汇聚于 Y 轴灭点 (E1, E2) 的透视圆：
同理，替换对应参数：
* u_2 = dx * cos(θ_2) + dy * sin(θ_2)
* v_2 = -dx * sin(θ_2) + dy * cos(θ_2)
* λ_2 = (D_k^2 + 2 * (r^2 / q) * u_2 - r^2) / (2 * v_2)
* C_x2 = X_O - (r^2 / q) * cos(θ_2) - λ_2 * sin(θ_2)
* C_y2 = Y_O - (r^2 / q) * sin(θ_2) + λ_2 * cos(θ_2)
* R_k2 = sqrt( (r * r_2 / q)^2 + λ_2^2 )
* 网格圆方程: (X - C_x2)^2 + (Y - C_y2)^2 = R_k2^2

### 3. 汇聚于 Z 轴灭点 (F1, F2) 的透视圆：
同理，替换对应参数：
* u_3 = dx * cos(θ_3) + dy * sin(θ_3)
* v_3 = -dx * sin(θ_3) + dy * cos(θ_3)
* λ_3 = (D_k^2 + 2 * (r^2 / s) * u_3 - r^2) / (2 * v_3)
* C_x3 = X_O - (r^2 / s) * cos(θ_3) - λ_3 * sin(θ_3)
* C_y3 = Y_O - (r^2 / s) * sin(θ_3) + λ_3 * cos(θ_3)
* R_k3 = sqrt( (r * r_3 / s)^2 + λ_3^2 )
* 网格圆方程: (X - C_x3)^2 + (Y - C_y3)^2 = R_k3^2
